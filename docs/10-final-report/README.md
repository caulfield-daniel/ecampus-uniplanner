## Итоги проекта

| Критерий | Результат |
|---|---|
| Траектория | Б — веб-ориентированная |
| Архитектура | PCMEF |
| Клиент | Веб (React + TypeScript, FSD) |
| Бэкенд | Kotlin + Spring Boot 3 + Spring Security (JWT) |
| База данных | PostgreSQL 16, Flyway |
| REST API | 18 эндпоинтов |
| Развёртывание | Docker + docker-compose |
