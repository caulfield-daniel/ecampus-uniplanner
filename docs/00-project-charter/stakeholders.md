# Стейкхолдеры

| Роль | Интерес | Влияние |
|---|---|---|
| Студент (конечный пользователь, `ROLE_USER`) | Видеть актуальное расписание, вести задачи и заметки, привязанные к занятиям, без ручного ввода расписания | Высокое — основной потребитель ценности продукта |
| Менеджер группы (`ROLE_MANAGER`) | Расширенные права в рамках своей группы (задел роли, детальные сценарии не входят в обязательный объём трактории Б) | Среднее |
| Администратор (`ROLE_ADMIN`) | Управление данными расписания на уровне системы (см. отложенный пункт «админ-панель» в [10-final-report/summary.md](../10-final-report/summary.md)) | Среднее |
| Преподаватель (методист курсового проектирования) | Оценка соответствия требованиям методички трактории Б, защита проекта | Высокое — оценивает результат |
| Разработчик (автор проекта) | Защита курсового проекта, переиспользуемая архитектура (KMP-задел под мобильный клиент) | Высокое |
