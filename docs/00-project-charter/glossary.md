# Глоссарий

| Термин | Определение |
|---|---|
| Занятие (Lesson) | Единица расписания: дисциплина, тип (лекция/практика/лабораторная), время, преподаватель, аудитория, привязка к учебной группе и дате |
| Привязка к занятию (`relatedLessonId`) | Необязательная связь задачи или заметки с конкретным занятием в расписании |
| Парсер | Отдельный микросервис (Python/FastAPI), забирающий расписание с сайта вуза (ecampus.ncfu.ru) и хранящий его в собственной БД |
| Синхронизация (sync) | Процесс, при котором backend забирает у парсера уже накопленные данные расписания группы и кладёт их в свой кэш (`cached_lessons`) |
| Личный вход в ИС вуза | Флоу, при котором пользователь подключает свой личный аккаунт ecampus.ncfu.ru через капчу (`UniversityAuthController`), отдельно от сервисного аккаунта парсера |
| KMP shared-модуль | Kotlin Multiplatform модуль с общими DTO и правилами валидации, компилируемый и в JVM (backend), и в JS (фронтенд) |
| PCMEF | Архитектурный паттерн Presentation-Control-Mediator-Entity-Foundation, к которому приведён backend-монолит |
| FSD | Feature-Sliced Design — архитектурная методология фронтенда (слои app/pages/widgets/features/entities/shared) |
