## Ключевые решения этапа

- Траектория Б: один веб-клиент (React) + сервер (Spring Boot) + REST API + PostgreSQL.
- Парсер расписания — вспомогательный микросервис, а не второй UI-клиент (не повышает траекторию).
- KMP shared-модуль и Android-задел — архитектурный запас на будущее, не обязательное требование.
