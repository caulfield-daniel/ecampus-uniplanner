## Почему архив

Проект вырос за рамки курсового: после защиты появились FSD-рефакторинг фронтенда, KMP-фундамент с JSON-Schema пайплайном, миграция тулчейна (Bun, JDK 25, Kotlin 2.4) и CI. Требования методички (траектория Б, минимальный набор страниц/эндпоинтов, формат отчёта) больше не являются ограничениями развития, поэтому курсовой пакет отделён от живой документации, чтобы не создавать противоречий.
