## Ключевые решения этапа

- Тела запросов (`*Input`/`*Request`) не несут jakarta-валидацию — валидация вызывается явно в Control через `ModelValidators` из shared-модуля, чтобы не ломать KMP/JS-совместимость.
- `lessonId` как query-параметр переиспользует существующие `GET /tasks`/`GET /notes`, а не вводит отдельные эндпоинты — меньше поверхности API при том же функциональном покрытии.
