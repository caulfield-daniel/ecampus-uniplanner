# Этап 01: Требования

## Обзор этапа

Формализованы функциональные требования к системе: построены доменная модель, Use Case диаграмма, спецификации вариантов использования и матрица трассировки от требований методички к реализации.

## Ключевые решения этапа

- Доменная модель разделена на ядро (полноценные Entity с бизнес-методами и инвариантами) и read-only справочники, источником которых является внешний микросервис-парсер.
- Привязка задачи/заметки к занятию (`relatedLessonId`) выделена в отдельный UC-06, т.к. затрагивает и backend (миграция, фильтрация), и фронтенд (виджет, бейджи, фильтры).
