# Этап 08: Развёртывание

## Обзор этапа

Backend и БД развёртываются через Docker Compose; фронтенд — отдельной статической сборкой. Парсер — независимый процесс со своей БД.

## Артефакты

| Файл | Описание |
|---|---|
| [admin-guide.md](admin-guide.md) | Инструкция по развёртыванию backend/БД/фронтенда, переменные окружения, известные ограничения |

## Ключевые решения этапа

- Flyway применяет миграции автоматически при старте backend — без отдельного шага «накатить схему вручную».
- CI/CD не реализован — не входит в обязательные требования трактории Б; сборка/проверка перед защитой выполняется вручную.
