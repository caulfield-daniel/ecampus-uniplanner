# Этап 06: Тестирование

## Обзор этапа

Backend покрыт юнит-тестами слоя Mediator (Service) — 32 теста, MockK + JUnit5, JaCoCo для отчёта покрытия. Дополнительно проведена сквозная (живая) проверка через Docker Compose с реальной БД, выявившая и устранившая баг, не видимый юнит-тестам.

## Артефакты

| Файл | Описание |
|---|---|
| [tests.md](tests.md) | Стратегия тестирования, перечень тестовых классов, запуск, покрытие |

## Ключевые решения этапа

- Тестируется только Mediator — наибольшая концентрация бизнес-логики при наименьшей стоимости поддержки тестов (без поднятия Spring-контекста).
- Юнит-тесты дополнены обязательной живой проверкой перед защитой — два метода взаимно дополняют друг друга (см. находку в [tests.md](tests.md)).
