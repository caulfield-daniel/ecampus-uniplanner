# Руководство пользователя

## Регистрация и вход

1. Откройте приложение — вы попадёте на экран **Login** (`/login`).
2. Для нового аккаунта заполните email, пароль, ФИО и название учебной группы (как в расписании вуза) и нажмите «Зарегистрироваться».
3. Войдите с этим email и паролем — вы окажетесь на дашборде «Сегодня».

## Дашборд «Сегодня»

Главный экран после входа показывает:
- сколько занятий у вас сегодня;
- сколько активных задач и заметок;
- список занятий на сегодня — клик по занятию открывает детальную панель;
- ближайшие 3 задачи и последние 3 заметки.

## Расписание

Раздел **Расписание** (`/schedule`) показывает занятия по неделям:
- стрелки переключения недели — Пн–Вс;
- клик по занятию открывает панель «Задачи»/«Заметки» этого занятия;
- клик по предмету в сайдбаре слева фильтрует расписание только по этой дисциплине.

## Привязка задачи или заметки к занятию

В детальной панели занятия (открывается кликом на занятие в расписании или на дашборде):
- вкладка **Задачи** — список уже привязанных задач, кнопка «+ Добавить задачу к занятию»;
- вкладка **Заметки** — аналогично для заметок.

Привязанные задача/заметка автоматически получают пометку с названием дисциплины и датой занятия — видно на общих страницах «Задачи»/«Заметки».

## Задачи и заметки

На страницах **Задачи** (`/tasks`) и **Заметки** (`/notes`):
- кнопка «Новая задача»/«Новая заметка» в правом верхнем углу — создание без привязки к занятию;
- выпадающий список рядом с кнопкой — фильтр: «Все», «Без привязки к занятию» или конкретное занятие;
- клик по задаче/заметке — редактирование; иконка корзины — удаление;
- чекбокс у задачи — отметка выполнения; цвет даты дедлайна меняется при приближении срока.

## Личный аккаунт ИС вуза (backend готов, экран в разработке)

В системе реализован backend-флоу для подключения личного аккаунта ecampus.ncfu.ru через капчу (`/university-auth/*`) — отдельно от группового расписания, которое видно сразу после регистрации. Экран для этого флоу во фронтенде на текущей итерации не реализован — функциональность доступна через API (Swagger UI), но не из интерфейса приложения.
